# TANZABOOST – Full Business, Marketing & Affiliate Plan (2025)

## 🎯 Ziel des Projekts
TanzaBoost bietet Webseiten für lokale Unternehmen (Bars, Lodges, Ärzte, Makler) für **60 000 TSH einmalig**, ohne monatliche Kosten.  
Server: Eigener Linux-Server mit Subdomains (z. B. bar.tanzaboost.com).

## 💰 Preisstruktur
- Webseite: **60 000 TSH**
- Hosting: **Kostenlos**
- Domain optional: **+30 000 TSH**
- Affiliate-Vergütung: **10 000 TSH pro Verkauf**
- Unterpartner: **2 000 TSH pro Verkauf**

## 🧩 Affiliate-System
1. Verkäufer registriert sich.
2. Erhält Code (z. B. TAZ123) + Google Form Link (?ref=TAZ123).
3. Sendet WhatsApp-Nachricht an Kunden.
4. Kunde füllt Formular aus.
5. Nach Zahlung: Provision via M-Pesa.

## 📋 Google Form Felder
Business Name, Owner, Phone, Type, Location, Description, Upload, Affiliate Code (versteckt per prefilled link).

## 📈 Wachstum
**Phase 1:** 200 Verkäufer in Tansania (30 Tage)  
**Phase 2:** 2000 Verkäufer in Ostafrika (3 Monate)  
**Phase 3:** 10 000 Verkäufer Afrikaweit (12 Monate)
